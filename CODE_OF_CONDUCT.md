# Code of Conduct

OMP Desktop aims to provide a constructive, technical, and welcoming environment for contributors and users.

## Expected behavior

Participants are expected to:

- discuss ideas and code respectfully and in good faith;
- focus criticism on technical decisions and observable behavior;
- provide enough context for others to reproduce problems;
- respect privacy and avoid publishing another person's sensitive information;
- accept maintainer decisions about project scope, architecture, and release policy even when disagreeing with them.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate disruption, doxxing, publication of secrets or private data, and repeated hostile behavior are not acceptable in project spaces.

## Scope

This code applies to repository issues, pull requests, discussions, reviews, release-related communication, and other spaces where someone is participating as a member of the OMP Desktop community.

## Enforcement

Report conduct concerns privately to the maintainer rather than escalating them in a public thread. The maintainer may edit or remove content, close or lock discussions, reject contributions, or restrict participation when necessary to protect the project and its participants.

Good-faith technical disagreement is welcome. Enforcement is about behavior, not about requiring agreement.
