# Ревизия PR, issues и Code scanning перед 0.9.15

Дата среза: **21 ноября 2026 года**. Исходная база — `main` **`ae7a41578157ccb7028425ff97c49b5286088d8b`**, опубликованный immutable prerelease [v0.9.14](https://github.com/Omnividente/omp-desktop/releases/tag/v0.9.14), подготовленный через [#375](https://github.com/Omnividente/omp-desktop/pull/375). Проверены **все 39 открытых на момент среза PR**, три открытых issues и Code scanning. Набор исходных heads зафиксирован в таблице ниже; поздние изменения исходных веток требуют нового сравнения.

**Результат выбора состава: 33 PR подготовлены к включению в кандидата, 4 отложены, 2 предложения устарели и подлежат закрытию.** «В кандидат» означает принятый узкий контракт и подготовленный перенос в рабочих ветках аудита. Документ пока **не утверждает merge в main, успешный общий CI или выпуск 0.9.15**. Итоговый integration PR, source SHA и runs дополняются после фактического результата в последнем разделе.

Публикация release или prerelease сама по себе не сливает PR. Она фиксирует выбранный commit/tag. Содержимое открытого PR может отсутствовать в tag, быть уже перенесено через другую композицию либо оставаться отдельным исследованием. Поэтому статус исходного PR проверяется по коду и происхождению изменений, а не выводится из номера выпущенной версии. Точный перенос и закрытие источников фиксируются также в [#177](https://github.com/Omnividente/omp-desktop/issues/177).

## Происхождение и взаимодействия изменений

Автор внешнего предложения [#250](https://github.com/Omnividente/omp-desktop/pull/250) — `mfkeeq199458`; отсрочка не меняет это авторство. Источники #256/#257/#259/#350 принадлежат `dependabot[bot]`. Остальные PR в этом срезе опубликованы `Omnividente`; исходные авторы коммитов, source heads и прежние предложения Dot сохраняются в переносах и карточках PR. Историческое авторство Jules не переатрибутируется. Новые DOT-номера этой ревизией не назначаются; прежний индекс остаётся в [PROPOSALS.md](PROPOSALS.md).

### Почему #338 закрывается как заменённый

Проверены результирующие версии всех шести изменённых файлов: `prepare-production-assets.mjs`, `production-native-ui.py`, `run-production-native-smoke.mjs`, оба production smoke workflow и README. Основные необходимые изменения перенесены/переработаны в #375: scoped authenticated API reads, actions read permission, staged AppImage replacement, архив на исходном томе, реальные version/chooser/PTY наблюдения.

Main дополнительно проверяет owned foreground surface, ограничивает повтор native mutations, сужает возвращаемые diagnostics и проверяет размер/pin installer до исполнения. Побайтового включения #338 нет: например, его quota-reset дополнение к сообщению API и расширенные native diagnostics не перенесены, а `WEBKIT_DISABLE_COMPOSITING_MODE` отсутствует. Эти хвосты не требуют возврата старого harness 0.9.13. Прежние failure/cancelled native runs остаются историческими отрицательными результатами; их нельзя считать приёмкой 0.9.15.

### #13 существует только в Remote PR ref

[#13](https://github.com/Omnividente/omp-desktop/security/code-scanning/13), `js/file-system-race`, относится к `refs/pull/239/merge`, `registry-client.mjs`; main такого файла не содержит. Локально прошли 13 security cases, включая normal/regular replacement/symlink/permissions/after-open/FIFO. Alert не следует автоматически закрывать потому, что его нет на default branch: он отслеживается в Remote milestone. После применения #300 нужен анализ соответствующего ref; если CodeQL по-прежнему отмечает lstat/open pattern, обоснование должно разбирать descriptor validation, а не скрывать правило целиком.

## Проверки и практические ограничения

На момент этого документа завершены source reviews, U/R focused gates, independent UI review и security guard tests. Для prepared security head `99601927ebf844cb7d8ce6c65f686da36505dfd1` прошли diff whitespace check и проверка объединённого Cargo.lock: 609 packages, все dependency references однозначны. В lock остаются `sha2 0.10.9` для transitives и direct `0.11.1`; это не случайный откат обновления.

Следующие проверки относятся уже к **точному общему кандидату**, не к сумме отдельно зелёных веток:

| Gate | Требуемый результат / состояние этого отчёта |
|---|---|
| Общая frontend-композиция | Locked install, typecheck, format, lint, полный Vitest и release-assets tests; final SHA/run ещё не зафиксирован здесь. |
| Rust на sit7-upr и HomePC | fmt, clippy с -D warnings, cargo test и updater-e2e feature check на одном source SHA; actual Linux PTY case из #363 и Windows fallback обязательно входят в evidence. Итог дополняется владельцем интеграции. |
| CodeQL на общем head | Отдельно от source PR scans; проверяются новые findings и ref каждого alert. Dismissal не подменяет анализ нового кода. |
| Native UI | Минимальное/широкое окно, много вкладок/длинные названия, scroll arrows/wheel/focus, отсутствие потери terminal draft; доступные Windows/Linux сценарии перечисляются точно. DOM geometry и composition events не являются physical DPI/IME proof. |

Репрезентативный discovery benchmark, Remote feature acceptance и native folder drop не блокируют выбранный maintenance scope, поскольку их реализации исключены. Их открытые PR/issues не считаются мусором или потерянными исправлениями.
